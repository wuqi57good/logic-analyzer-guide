# 逻辑分析仪从零到实战

看懂数字信号的时序与协议。面向嵌入式新手的单文件离线互动教程。

- 在线阅读：https://wuqi57good.github.io/logic-analyzer-guide/
- 离线使用：下载仓库内的 `logic-analyzer-guide.zip`，解压后双击 `index.html`。
- 13 章、9 个交互实验、39 道自检题；包含 USB 产品示意、逐位协议演示和完整排障案例。
- 原生 HTML、CSS、JavaScript 全部内联，不需要构建工具、CDN 或在线字体。
- 信息核实日期：2026-11-09；资料来源列在教程附录。

## 发布方式

GitHub Pages 从 `main` 分支根目录发布，首页为 `index.html`。`.nojekyll` 让 GitHub 直接提供静态文件。

教程里的可调门限及高级触发会明确区分教学仿真与设备实际能力。接线前核对器材电气规格，仅测已确认安全的低压数字电路。
